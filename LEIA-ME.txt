PAINEL DOS BARBEIROS (agenda.html) — pasta para o Cloudflare Pages

O que tem aqui:
- agenda.html       (o painel)
- manifest.json     (nome/ícone do app)
- sw.js             (deixa o app abrir offline/mais rápido)
- icon-192.png / icon-512.png (ícones do app)
- favicon.png       (ícone da aba do navegador)

Antes de subir:
1. Abra o agenda.html, procure "COLE_AQUI" e cole o MESMO firebaseConfig usado no site
   dos clientes (é o mesmo projeto Firebase).
2. No Firebase, ative "E-mail/senha" em Authentication e crie uma conta para cada barbeiro.
3. Cole as regras do Firestore (Firestore → Rules) — inclui a coleção nova "bloqueios"
   usada pra barbeiro bloquear um dia:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /agendamentos/{doc} {
      allow create: if request.resource.data.keys().hasOnly(['service','barber','date','time','name','phone','status','createdAt'])
                    && request.resource.data.barber in ['Rafael Marques','Diego Da Silva Lourenço']
                    && request.resource.data.name is string && request.resource.data.name.size() > 0 && request.resource.data.name.size() < 80
                    && request.resource.data.phone is string && request.resource.data.phone.size() > 0 && request.resource.data.phone.size() < 20
                    && request.resource.data.status == 'pendente';
      allow read, update, delete: if request.auth != null;
    }
    match /bloqueios/{doc} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

Como subir no Cloudflare Pages:
1. dash.cloudflare.com → Workers & Pages → Create → Pages → Upload assets.
2. Arraste TODOS os arquivos desta pasta.
3. Cloudflare te dá um link tipo nomeousado.pages.dev.

Pra virar app (.apk):
1. Depois de publicado no Cloudflare, cole o link em pwabuilder.com.
2. Ele já vai reconhecer o manifest.json e os ícones automaticamente.
